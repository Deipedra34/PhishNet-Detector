PhishNet Detector – Settings

Where your phishnet serve instance is listening. The default, http://localhost:8080, matches phishnet serve and the Docker image run with -p 8080:8080. For another port or machine, enter e.g. http://localhost:9090 or http://192.168.1.20:8080.

Privacy

Pages are only checked when you click the PhishNet toolbar icon. The extension then sends that one page's address to the API address above - your own server - and nowhere else. Nothing runs in the background.
